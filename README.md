# dr.skill

一份中文教学聊天文风技能：话题前置、逗号停顿、短句补说、具体动作，以及直接而亲切的要求与回应。

仓库名与显示名是 **dr.skill**。技能标识为 **dr**，调用时使用 **`$dr`**。

## 文件

- [技能入口](dr/SKILL.md)：生成和改写规则。
- [风格解析](dr/references/style-analysis.md)：语序、标点、消息节奏、场景差异、证据强弱和样本统计。
- [原创示例](dr/references/examples.md)：21 组练习，含事实保真、强度对比与反例。

## 使用

将仓库中的 `dr` 文件夹放进你的技能目录（如 `~/.codex/skills/dr`），在支持技能的客户端刷新技能列表或开启新聊天后调用：

```text
请用 $dr 改写：这份练习必须完成，请周二晚上之前提交。
```

默认一小句一段，空行隔开，日常回复保持简短。也可以要求“自然一点”或“更像现场答疑”。只返回正文，不自动向群聊发送。

规则由经授权的两个教学群聊样本归纳，检索范围为 2026-09-14 至 2026-10-14；历史可能不完整。公开仓库不含群聊导出、完整原话、成员账号或访问凭据。所有示例都是原创、虚构情境，不能当作真实教学安排。

这份技能模仿文风，不代表原说话者，也不保证复现每次发言。事实、技术内容和任务要求始终优先于风格。
